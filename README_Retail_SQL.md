# Retail Sales Analysis Using SQL

A SQL project analyzing retail transactions in MySQL. The queries focus on preparing transaction data, comparing sales patterns, and summarizing customer and order behavior.

## Project goals

- Check transaction data for missing values and remove incomplete records.
- Analyze sales by product category and identify top customers.
- Compare transaction patterns across gender and product categories.
- Summarize sales timing and find the best-selling month in each year.

## Tools

- MySQL
- SQL aggregations and filtering
- Common table expressions (CTEs)
- Window functions, including `RANK()`
- `CASE` expressions

## Project file

- `Reatil_project's_query.sql` — SQL queries for the retail sales analysis.

## Analysis overview

The project uses filters, grouping, aggregations, CTEs, `RANK()`, and `CASE` to explore the transaction data and produce concise summaries. The query file includes data checks, category and customer analysis, comparisons by gender and product category, and summaries by month and time of day.

## How to use

1. Open the SQL file in MySQL Workbench or another MySQL client.
2. Connect to the database and select the project dataset.
3. Review and run the queries in sequence, adjusting the database or table names if your local setup uses different names.
